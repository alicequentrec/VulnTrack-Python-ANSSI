# VulnTrack-Python-ANSSI
Ce pipeline Python automatise la veille cybersécurité en exploitant les flux RSS du CERT-FR. Il extrait les CVE, les enrichit via les API MITRE et EPSS, puis génère des analyses CSV et des visualisations (CVSS, timelines). L'outil inclut un système d'alertes par email pour réagir vite aux vulnérabilités critiques détectées.
